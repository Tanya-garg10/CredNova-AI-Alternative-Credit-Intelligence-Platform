# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/f2a24c2f-9061-4678-8598-2d1c5bf20ec7

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `FEATHERLESS_API_KEY` in [.env.local](.env.local) to your Featherless API key (get it from https://featherless.ai)
3. Run the app:
   `npm run dev`
